## Bundled in the AAR (engine payload)

### Chunker — MIT

`engine/src/main/java/com/hivemc/**`, `engine/src/main/java/org/iq80/**` and
`library/src/main/assets/chunkbridge/engine-res/**` are derived from
[Chunker](https://github.com/HiveGamesOSS/Chunker), Copyright (c) 2024 Hive Games, MIT license.
The trimming and changes made for this SDK are documented in [VERSION.md](VERSION.md); edited files keep
`ChunkBridge:` comments. Full text: [engine/LICENSE-CHUNKER](engine/LICENSE-CHUNKER).

### Arcana — Apache-2.0

`library/src/main/java/be/stef/arcana/**` is derived from [Arcana](https://github.com/RealBurst/arcana),
Copyright 2025 Stephane Bury, Apache License 2.0 (full text: [LICENSE-APACHE-2.0](LICENSE-APACHE-2.0)).

Only the extraction side is vendored, and only for the four containers the SDK supports: RAR 4/5, 7z, TAR and
TAR+GZIP, plus the decoders they need (bundled LZMA/LZMA2, PPMd, bzip2 and RAR decoders). Removed: the compressor,
the CLI, the other thirty-odd formats, the plugin system, detection/repair/split and the per-file console progress
bars. The parallel worker count is pinned to 2, and the RAR decoder's progress output is disabled by default.
Changes are marked with comments inside the original files; the Apache header of every file is kept.

## Maven dependencies (packaged into the engine dex)

| Artifact | Used for | License |
| --- | --- | --- |
| `com.google.guava:guava:33.4.0-jre` | Chunker collections and utilities | Apache-2.0 |
| `com.google.code.gson:gson:2.14.0` | Chunker's JSON data tables | Apache-2.0 |
| `it.unimi.dsi:fastutil:8.5.19` | Chunker's primitive collections | Apache-2.0 |
| `net.jpountz.lz4:lz4:1.3.0` | LZ4 compression of Bedrock NBT | Apache-2.0 |
| `com.hivemc.leveldb:leveldb:1.1.0`, `leveldb-api` | LevelDB storage used by Bedrock worlds | Apache-2.0 (fork of Google's BSD-3-Clause LevelDB) |
| `com.google.code.findbugs:jsr305` (compile-only) | Nullability annotations | Apache-2.0 |

Guava **must stay pinned**: 33.4.8+ uses `VarHandle`, which crashes below API 33; `:engine:engineDex` fails the build
if the produced dex references it.

## Maven dependencies of the SDK module itself

`com.frenetic.chunkbridge:chunkbridge` declares `com.frenetic.chunkbridge:api` (this repository, MIT) and the Kotlin
stdlib that the Android Gradle Plugin adds to every library module (Apache-2.0). The SDK's own code is Java only.

## Not included

- No Minecraft assets, data, or code. This project is not affiliated with Mojang Studios or Microsoft; Minecraft is a
  trademark of Mojang Studios. The engine bundles only community-maintained block/format mappings and a Java font
  metrics table, which are part of Chunker.
- No player worlds. Test worlds are supplied locally and are not committed (see
  [docs/INTEGRATION.md](docs/INTEGRATION.md#testing-your-integration)).

## Build outputs

`library/src/main/assets/chunkbridge/engine.jar` and `formats.json` are not in the repository. They are generated by
`:engine:engineDex` (R8 + D8 from this repository's `engine` and `api` sources) and `:engine:dumpFormats` during the
build.
